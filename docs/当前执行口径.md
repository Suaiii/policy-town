# 大厂 Town · 当前执行口径

> v3.1 配套决策记录。本文用于解决历史方案之间的冲突，优先级高于 v2，低于用户最新明确要求。

## 一、优先级

1. 产品性：用户能选择、运行、干预、查看、比较，并得到一份可读交付物。
2. 演示效果：5 分钟内完成一次操作闭环，画面变化清楚，结果有反转。
3. 机制自洽：政府、企业、员工和外包商的动作能在同一世界状态中互相影响。
4. 可信表达：明确区分场景演示、背景知识和现实预测。
5. 实验部分：仅保留支撑产品可信度所必需的对照，不追求论文式实验规模。

## 二、文档权威顺序

- 当前产品与演示：`产品框架_v3.md`。
- 价值主张与边界：`价值主张与能力边界.md`。
- 历史构想：`archive/政策回音壁_产品框架_v2.md`，不可作为当前交付承诺。
- 比赛要求纪要：仅作方向参考；录音转写存在遗漏、口语化和 AI 生成标注，不逐字当作硬性评分表。

## 三、当前必须跑通的闭环

```text
选择政策世界线
  → 开始推演并看到城市/企业状态变化
  → 投放一张事件卡
  → 点击一个部门、企业或员工的决策
  → 切换另一条世界线比较
  → 导出一页政策简报
```

## 四、演示口径

- 所有精确数字都标注为“场景指数”或“演示数据”，不冒充现实预测。
- 预录回放必须来自真实运行快照；UI fixture 仅用于开发，必须带水印。
- 结论用“本场景中出现了……”而不是“现实中一定会……”。
- 溯源面板展示信息来源、目标、规则版本、动作 JSON 和决策摘要，不把自然语言 reasoning 当作因果证明。

## 五、当前不做

- 不做个人被裁时点预测。
- 不承诺 100 个 agent、16 期、五组实验或九类场景。
- 不在没有运行快照时用 mock 数据讲正式结果。
- 不把虚拟政策参数直接表述为现行法律结论。
