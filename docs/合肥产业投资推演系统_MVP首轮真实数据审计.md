# 合肥产业投资推演系统：MVP 首轮真实数据审计

## 本轮入库范围

本轮按照抓取清单优先处理城市/财政骨架、京东方案例、需求侧政策、光伏政策、电子信息与集成电路政策，以及长鑫的 withheld 时间线。

新增或修正的数据包括：

- 合肥 2007—2016 年 GDP 序列的来源 URL 与公报可知日期；
- 合肥 2008—2016 年固定资产投资序列（2007 待补）；
- 合肥财政总收入、地方财政收入、部分税收收入与 2016 年财政支出；
- 京东方 2008 年营业收入、净利润、经营现金流、总资产、所有者权益和派生负债；
- 京东方合肥项目截至 2009-04-21 的累计增资与持股比例；
- 家电下乡、太阳能光电建筑补助、电子信息产业振兴、集成电路纲要等结构化政策；
- 长鑫 2016—2019 项目时间线，并继续作为截止日后的 withheld 信息。

## 真实数据进入引擎的方式

真实数据现已不仅仅进入溯源抽屉。后端通过确定性的 Context Builder 完成以下链路：

```text
SQLite observation / policy / event
→ information_available_date 截止过滤
→ 带公式和 evidence_id 的 0—100 分档
→ CityMetrics / CompanyState 初始值与阶段更新
→ Agent 分数和 state_delta
→ 终局方向、时序、机制、路径反馈与泄漏审计
```

当前已落地的映射包括：

- 工业增加值占 GDP 比重与家电产业占比映射为 `industrial_base`；
- 家电产值与产业占比映射为 `supply_chain_strength`；
- GDP 增速映射为 `market_cycle`；
- 固定资产投资与 GDP 映射为 `infrastructure_capacity`；
- 高校、学生与重点实验室映射为 `talent_supply`；
- 历史财政收入、支出、政府性基金与债务进入财政环境指数和财政 Agent 研判，但不生成玩家点数；
- 项目总投资映射为企业 `capital_intensity` 和 `capital_request`；
- 企业资产、负债、利润与经营现金流映射为 `financial_health` 和 `project_cashflow`；
- 行业增速映射为订单强度与供给压力。

每个派生值均输出公式、置信度和原始 `observation:*` 引用。缺少真实观测时保留 MVP 分档并继续标识数据缺口，不把缺失值伪装成观察事实。

Historical Replay 不再使用固定得分。方向得分读取 `case_library` 的结果标签，时序得分读取四阶段建设轨迹，机制得分读取有真实证据的 `state_delta` 比例，路径反馈读取城市资产变化，泄漏审计检查每轮是否存在晚于截止日的信息。

财政池采用滚动结转机制，但每阶段新增点数已降级为显式 `scenario_assumption`。当前玩法参数为 S1—S4 的 `100、60、45、30` 点；它们仅用于形成首投、追加、周期分化和终局下注的资源压力，不声称来自真实财政数据。真实宏观财政观测继续进入 Context 和财政 Agent，假设对象同时记录已尝试来源、缺失字段、数据缺口 ID 和未来 replacement key。

## 重要口径说明

1. 历史公报中的“财政收入”“地方财政收入”保留原词，没有改写成现代“财政总收入/一般公共预算收入”口径。
2. 2011 年合肥行政区划调整，新增庐江县和县级巢湖市。跨 2010—2011 的总量变化不能直接解释为经济增长。
3. 京东方 2008 年年报发布于 2009-04-21，因此其中年度财务数据不能进入 2008-09-12 的决策 Context。
4. 京东方负债 72.22318699 亿元由总资产减所有者权益派生，数据库备注中保留了公式来源。
5. 部分合肥统计公报目前仅找到官方公报转载页，质量标记为 B；后续找到统计局原页或年鉴后再升级为 A。

## 可直接开跑的第一个场景

第一炮建议使用 `CASE-02 京东方合肥项目`，信息截止日设为 `2008-09-12`。

允许进入 Context：

- 2007 年已经发布的合肥城市与家电基础；
- 2008-09-12 前已经公开的国家政策与宏观信息；
- 项目框架协议当日公开给决策者的信息。

禁止进入 Context：

- 2008 全年统计公报（2009-03-18 才发布）；
- 京东方 2008 年年报（2009-04-21 才发布）；
- 项目公司成立、开工、后续增资和最终成功结果。

需要注意：当前数据库尚缺京东方在 2008-09-12 前最近一期可公开财务报表，以及当时可知的项目资本金和政府出资细目。因此第一炮可以测试信息截止、Agent 分工和证据引用，但还不能把财政承受结论当作最终历史校准结果。

## 首轮来源

- 合肥年度统计公报转载索引：2007—2016 各年度来源已经写入 `source` 表。
- 京东方 2008 年年度报告摘要：巨潮资讯原始 PDF。
- 长鑫存储发展历程：公司官网。
- 家电下乡：财政部、商务部、工业和信息化部通知。
- 太阳能光电建筑应用补助：财政部财建〔2009〕129号。
- 电子信息产业调整和振兴规划：国务院办公厅文件转载页。
- 国家集成电路产业发展推进纲要：工信部来源转载页。
- “十三五”国家战略性新兴产业发展规划：国务院文件转载页。
