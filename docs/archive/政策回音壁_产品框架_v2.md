# 第一部分 · 用户交互全景

老师那句「怎么吸引大家来用」是评分重点。所以先定义**用户能做什么**，再谈系统怎么实现。

## 1.1 五类交互，按参与深度排列

```
L1 配置        开局设定实验条件            ── 研究者姿态
L2 干预        运行中插手                  ── 上帝姿态
L3 审讯        追问 agent 为什么           ── 观察者姿态
L4 对比        并排看不同世界线            ── 分析者姿态
L5 扮演        自己下场当政府/企业/员工     ── 玩家姿态 ★吸引力主要来源
```

---

## 1.2 L1 · 配置交互（开局）

用户在开跑前设定这个世界长什么样。

| 交互 | 控件 | 用户看到的即时反馈 |
|---|---|---|
| 选场景剧本 | 三选一：行业下行 / 补贴退坡 / 监管新规 | 剧本简介卡 |
| 设政策初值 | 裁员门槛、补偿倍数、执法强度、补贴方案 | 政策文本自动生成预览 |
| **设三方先验** | 三个滑块：企业对政府的信任、**员工对维权的信心**、公众舆论敏感度 | 分布直方图实时变化 |
| 设企业构成 | 数量、资产可迁移性分布、财务压力分布 | 企业卡片墙 |
| 设员工构成 | 各群体比例、储蓄缓冲、家庭负担 | 劳动力结构饼图 |
| 选运行期数 | 8 / 16 / 24 期 | 预估耗时 |

**先验滑块是这个产品的灵魂控件**。老师原话「先验预期会最影响分布的匹配程度」——所以我们把它做成开局第一屏最显眼的东西，而不是埋在高级设置里。

---

## 1.3 L2 · 干预交互（运行中）

跑的过程中随时插手。这是 AgentSociety 的核心借鉴点。

| 交互 | 说明 |
|---|---|
| **暂停 / 单步 / 变速** | 基础播放控制 |
| **临时改政策** | 第 7 期突然加码补偿标准，看已经在协商中的谈判怎么变 |
| **投放突发事件卡** | · 某厂裁员上热搜<br>· 一起仲裁案员工胜诉并被广泛报道<br>· 某大厂宣布总部迁离<br>· 行业黑天鹅（大模型冲击岗位）<br>· 政策传闻（真假可控）★ |
| **注入谣言** | 向社交场景投放一条未证实信息，追踪它的扩散路径——斯坦福小镇「情人节派对」那个实验的直接对应物 |
| **定向冲击** | 指定某一家企业遭遇现金流危机，看它的动作和溢出效应 |
| **回滚重跑** | 从第 N 期分叉，换个政策再跑一遍，生成平行世界线 |

> **谣言注入 + 传播路径追踪**是最容易出彩的一个交互。用户投一条"听说下季度补偿标准要下调"，然后看着这条消息在脉脉场景里扩散、员工提前签字、企业提前动手——一条假消息改变了真实结果。这个演示效果非常强。

---

## 1.4 L3 · 审讯交互（观察与溯源）

对应老师说的「能不能追溯到决策链条」。

| 交互 | 用户操作 | 返回 |
|---|---|---|
| **点开决策** | 点任意 agent 任意一期 | 完整 reasoning + 当时的信息集 + 输出 JSON |
| **发问卷** | 选目标群体，出题 | 分布统计图（可对比不同期数） |
| **做访谈** | 选单个 agent，自由提问 | 该 agent 以其身份和记忆回答 ★ |
| **看信息溯源** | 点某个 agent 的某个判断 | 「它是从哪听说的」链路图 |
| **看关系网** | 切换网络视图 | 谁跟谁在哪些场景相遇过、传了什么 |
| **归因追问** | 「如果没有第 5 期那条政策，你会怎么做？」 | agent 的反事实自述（软证据，需标注） |

**访谈是最有产品感的交互**。用户可以直接问一个刚被裁的员工 agent：「你为什么签字了？」它会基于自己的储蓄缓冲、家庭负担、对仲裁胜率的判断给出回答。评委会记住这个。

## 1.5 L4 · 对比交互（反事实）

| 交互 | 呈现 |
|---|---|
| 双栏世界线对照 | 左右并排，时间轴同步 |
| 指标 delta 视图 | 只显示差值曲线 |
| **同一 agent 跨世界线对照** | 同一家企业在 A 组和 B 组第 8 期的推理并排——直接看出政策改变了它的哪一句判断 ★ |
| 旋钮扫描 | 门槛从 5 扫到 100，输出尖峰位置的移动动画 |
| 泄漏桑基图 | 管制收紧后，人流从"正式裁员"流向了哪些渠道 |

## 1.6 L5 · 扮演交互（差异化亮点）

用户下场，跟 agent 对抗。三个视角各有一套输赢逻辑：

### 坐政府位
你发政策，企业和员工 agent 应对。
- **你的 KPI 面板**：就业稳定 / 财政收入 / 舆情风险 / 招商竞争力
- **失败体验**：你会发现自己的 KPI 好看了，但总就业变差了
- **一句话**：「你的政策会被怎么绕开」

### 坐企业位
你经营一家公司，要在合规、成本、舆情、员工士气之间平衡。
- **你的动作**：渠道组合、校招名额、是否申领补贴、要不要跟政府谈
- **失败体验**：你选了最省钱的渠道，结果上了热搜，骨干跑了一半
- **一句话**：「同行会怎么动，市场会怎么变」

### 坐员工位 ★情感冲击力最强
你被通知优化，HR 坐在对面。
- **你的选择**：签字拿 N+1 / 拒签拖判 / 申请仲裁 / 发脉脉曝光 / 接受转岗
- **你的约束**：储蓄能撑几个月、房贷、简历空窗、行业口碑
- **失败体验**：你拖了四个月赢了仲裁，多拿两个月工资，但错过了招聘季
- **一句话**：「政策保护的是谁」

> 三个视角轮流玩一遍，用户会自己得出那个结论——**没有人是坏人，但结果对所有人都更糟**。这比我们直接说出来有力得多。

# 第二部分 · 三方博弈结构

## 2.1 三角关系

```
              政府
          ↙        ↖
    管制/补贴      舆情/仲裁/信访
    迁移威胁/游说   保护承诺/维权便利度
         ↘          ↗
      企业 ←─────→ 员工
       解雇渠道选择 / 接受·抗争·曝光
```

**三方各自的既要又要**：

| 主体 | 要 A | 要 B | 冲突点 |
|---|---|---|---|
| 政府 | 就业稳定（当下考核） | 投资留存与财政（长期） | 逼太紧企业就走 |
| 企业 | 降本增效（资本市场） | 雇主品牌与政府关系（下一轮） | 省钱的渠道最容易上热搜 |
| **员工** | **补偿金最大化** | **尽快再就业** | **拖越久补偿越高，但简历空窗越长** |

员工那一行是 v2 新增的核心。**这个两难是真实存在的，而且它决定了企业敢用哪些渠道**——如果员工普遍撑不起拖延成本，企业就敢压价逼退。

## 2.2 员工闭环为什么必须存在

没有员工方，模型是残缺的，因为**企业的渠道选择约束来自员工的反应**：

```
政府提高仲裁便利度
   → 员工的"维权胜率预期"上升
   → "调岗逼退"这个渠道失效（员工不接受了）
   → 企业被迫转向成本更高的正式协商
   → 但同时更不敢招人
   → 校招进一步收缩
```

这条链路**没有一个环节是写死的规则**，它是三方交互涌现出来的。这是评委最想看的东西：个体行动导致群体层面的结果。

# 第三部分 · 智能体设计

## 3.1 员工 Agent（v2 重写）

### 状态变量

```yaml
worker_id: W042
group: "3年内工程师"        # 用于聚合展示
firm_id: F03

# 生存约束 —— 决定议价能力
savings_months: 4          # 能撑几个月 ★核心
family_burden: 0.7         # 房贷/子女 0-1
age_band: "28-35"

# 市场位置
skill_level: 0.6
replaceability: 0.7        # 可替代性，决定企业先动谁
job_market_belief: 0.4     # 对再就业难度的预期

# 信念 —— 决定抗争意愿
rights_prior: 0.3          # 相信维权能赢的概率 ★核心旋钮
gov_trust: 0.4             # 相信政府会真的保护自己

# 社会位置
network_reach: 0.2         # 社交媒体影响力 → 曝光杀伤力
peers: [W011, W087, ...]   # 跨公司的同行关系

status: "在职"             # 在职/风声中/协商中/仲裁中/求职中/已再就业/退出
memory: []
```

### 动作空间

| 动作 | 需要什么条件 | 对企业的杀伤 | 对自己的代价 |
|---|---|---|---|
| 接受协商签字 | — | 无 | 补偿可能偏低 |
| 拒签、拖延谈判 | savings 够 | 时间成本 | 空窗期 |
| **申请劳动仲裁** | rights_prior 高 + savings 够 | 高（且会被同行看到） | 数月时间、行业标签 |
| **社交媒体曝光** | network_reach | 极高（触发舆情） | 求职风险 |
| 骑驴找马 | — | **骨干流失（逆向选择）** | 无 |
| 主动离职 | 有 offer | 中 | 无补偿 |
| 接受转岗/转外包 | — | 无（企业最想要的） | 待遇下降 |
| 集体协商 | 同事协同 | 极高 | 组织成本 |
| 技能投资/转行 | savings 够 | — | 长期收益 |
| 退出劳动力市场 | — | — | 计入隐性失业 ★ |

> **最后一条要单独说**：「退出劳动力市场」的人不计入失业率，但确实失业了。让沙盒把这部分显式算出来，是一个很有分量的输出指标。

### 决策 Prompt 骨架

```
你是一名 {age_band} 的 {group}，在 {firm_name} 工作 {tenure} 年。

【你的处境】
存款够你撑 {savings_months} 个月，家庭负担：{family_burden_desc}
你判断自己再找一份同等工作大约需要 {job_market_belief_desc}

【你的信念】
关于劳动仲裁：{rights_prior_desc}
关于政府保护：{gov_trust_desc}
（这些判断来自你的经历和你听到的事，不一定正确）

【本季发生了什么】
公司通知：{firm_action_to_you}
你在脉脉上看到：{social_feed}       ← 来自社交场景
你的同行的遭遇：{peer_news}
政府新政策：{policy_public}

【你的记忆】
{memory_recent_3}

你要做出选择。请先说出你的真实想法——包括你的犹豫、
你在权衡什么、你最担心什么——然后给出决定。
```

**注意最后那句**。让员工 agent 输出犹豫和担忧，而不只是结论。这些文本是溯源面板里最打动人的素材，也是 L3 访谈交互的基础。

# 第四部分 · 交互场景层（v2 新增）

## 4.1 为什么需要场景

斯坦福小镇的关键设计：**两个 agent 只有同时出现在同一地点，才会发生对话**。这不是装饰，它是信息不对称的实现机制——谁在哪，决定了谁知道什么。

v1 的设计里所有 agent 共享同一份广播信息，这是错的。v2 用场景来切分信息可见性。

## 4.2 场景清单

| 场景 | 参与方 | 信息可见性 | 产生什么 |
|---|---|---|---|
| **政策发布会** | 政府 → 全体 | 公开 | 政策文本、承诺 |
| **闭门征求意见** | 政府 ↔ 头部企业 | 仅参与者 ★ | 企业游说、政策预告泄漏 |
| **企业决策会** | 企业内部 | 私有 | 渠道组合决策 |
| **HR 谈话间** | 企业 ↔ 单个员工 | 双方私有 ★ | 一对一议价，核心场景 |
| **脉脉/社交媒体** | 员工 ↔ 员工（跨公司） | 半公开 ★★ | 信息扩散、爆料、谣言 |
| **劳动仲裁庭** | 员工 ↔ 企业，政府裁决 | 结果半公开 ★ | 判例，改变所有人的先验 |
| **招聘市场** | 企业 ↔ 求职员工 | 公开 | 匹配出清、起薪信号 |
| **行业闭门会** | 企业 ↔ 企业 | 仅参与者 | 观察同行、默契协同 |
| **12333/信访** | 员工 → 政府 | 政府可见 | 政治压力累积 |

## 4.3 场景的三个作用

**① 制造信息不对称**
参加了闭门征求意见的头部企业提前知道政策方向，中小企业不知道。这个差异会直接产生不同的行动时序，而且是**内生的优势**，不是我们硬塞的。

**② 承载信息扩散**
社交场景是 OASIS 的对应物。一条爆料在脉脉上传播 → 触达的员工更新 `rights_prior` → 他们的行为改变 → 企业发现某个渠道不好使了。

**扩散规则**（走规则不走 LLM，省钱且可控）：
```python
触达概率 = f(发布者 network_reach, 内容冲击力, 同行关系距离, 时间衰减)
```

**③ 让判例产生外部性**
一起仲裁胜诉，不只影响当事人。它在社交场景传播后，**全行业员工的 rights_prior 上升**。这是一个非常漂亮的涌现机制：单个员工的抗争改变了所有企业的成本结构。

## 4.4 场景在时序中的位置

```
① 环境更新                                    [规则]
② 政策发布会场景 → 政府决策与公告               [LLM]
③ 闭门场景     → 头部企业游说/获取内幕          [LLM，仅参与者]
④ 企业决策会   → 渠道组合与报价                 [LLM ×N，并行]
⑤ HR 谈话间   → 企业与员工一对一议价 ★          [LLM，配对]
⑥ 社交场景     → 爆料发布与扩散                 [LLM 发布 + 规则扩散]
⑦ 仲裁庭场景   → 案件裁决                       [规则 + LLM 判理由]
⑧ 招聘市场     → 匹配出清                       [规则]
⑨ 结算         → 就业/股价/财政/舆情            [规则]
⑩ 信念更新     → 三方 prior 贝叶斯更新          [规则]
⑪ 快照落库                                     [规则]
```

**成本控制**：⑤ 的一对一议价不能对所有员工跑，只对**抽样的代表性员工**跑 LLM（比如每家 3-5 个），其余按已跑出的行为模式做规则外推。这个折衷必须在展示时诚实说明。

# 第五部分 · 反事实旋钮（v2 修订）

## 5.1 新增的员工侧旋钮

| 旋钮 | 取值 | 预期看到 |
|---|---|---|
| **员工维权先验** | 低 / 中 / 高 / 高度分歧 | 企业渠道构成的整体位移 ★ |
| **储蓄缓冲分布** | 薄 / 正常 / 厚 | 议价能力 → 补偿金水平 |
| **仲裁便利度** | 低 / 中 / 高 | 间接管制 vs 直接管制的效果对比 ★ |
| **社交媒体活跃度** | 关闭 / 正常 / 高 | 信息扩散对均衡的影响 |

## 5.2 最小实验组（时间紧只跑这五组）

```
A 基线      无管制
B 直接管制  提高门槛 + 补偿倍数           → 出监管悖论
C 堵漏      B + 外包纳入监管              → 出泄漏转移
D 间接管制  只提高仲裁便利度，不改门槛 ★   → 与 B 对照，可能更有效且副作用更小
E 关闭社交  B + 社交场景关闭              → 证明信息扩散确实在起作用
```

> **D 组是 v2 新增的，而且我认为它是最有政策价值的一组**。它回答的问题是：与其直接管制企业，不如提高员工的维权能力——效果如何？这个对比是纯粹由三方结构产生的，v1 的两方模型做不出来。

1. **裁员规模分布直方图** —— 门槛左侧尖峰
2. **渠道构成堆叠图** —— 正式塌缩、变相膨胀
3. **校招名额曲线** —— 监管悖论的直接证据
4. **★ 员工结局桑基图** —— 从「在职」流向 签字/仲裁/曝光/主动离职/转外包，再流向 已再就业/仍失业/**退出劳动力市场**。这张图是 v2 的新主打，它把代价具象化了
5. **★ 三方满意度雷达** —— 政府 KPI / 企业利润 / 员工福利，三轴同时看。管制收紧后可能出现"政府 KPI 上升，另外两轴下降"的形状
6. **信息扩散动画** —— 一条爆料在员工网络中的传播路径
7. 信任度演化曲线（三方各一条：企业对政府、员工对政府、员工对维权）
8. 补贴有效率仪表盘

## 6.2 溯源面板增强

新增**「三方同一时刻」视图**：选定第 N 期，同屏展示政府、某企业、某员工在那一刻各自的推理。三段文本并排，能直接看到**三方对同一件事的理解完全不同**——这就是老师说的"你不知道他怎么想，他也不知道你怎么想"。

# 第七部分 · 实现优先级（时间紧的砍法）

```
必做（最小可行）
  ├ 环境引擎（时钟 + 景气度 + 匹配出清）
  ├ 企业 Agent（含完整渠道动作空间）
  ├ 员工 Agent（至少 3 个群体 × 抽样个体）
  ├ 政府 Agent（可先做外生政策，节省一轮 LLM）
  ├ HR 谈话间场景（三方交互的核心承载）
  ├ 主图 1、2、3、4
  └ 溯源面板

强烈建议做（性价比最高的加分项）
  ├ 社交场景 + 信息扩散（规则实现，成本低，效果好）
  ├ 仲裁庭 + 判例外部性
  ├ D 组实验（间接管制对照）
  └ L5 扮演模式的「员工视角」单个界面

时间不够就砍
  ├ 多城市政府竞争
  ├ 闭门征求意见场景
  ├ 行业闭门会
  ├ L5 的政府/企业视角
  └ 旋钮扫描动画
```

**扮演模式即使只做"员工视角"一个界面也值得做**——它是整个产品情感冲击力的来源，而且实现成本最低（一个对话界面 + 几个选项按钮）。

# 第八部分 · Demo 剧本（v2，6 分钟）

1. **[30s] 抛问题**：政府要限制大厂裁员，你觉得裁员会变少吗？

2. **[45s] ★ 先让评委当一次员工**：屏幕上是 HR 谈话间，"公司通知你被优化，给 N+1。你存款够撑 4 个月，有房贷。你选：签字 / 拒签 / 仲裁 / 曝光"。**让评委自己点一个**，然后展示 100 个 agent 在同样处境下的选择分布。

3. **[60s] 跑基线**：无管制，看三方满意度雷达的初始形状。

4. **[90s] 加管制**：正式裁员断崖下跌 → 分布图尖峰出现在 19 人 → 渠道桑基图显示人流转向外包和不续签 → 校招腰斩 → **员工结局桑基图显示"退出劳动力市场"这一支变粗了**。

5. **[45s] 反转**：三方满意度雷达——政府 KPI 涨了，企业和员工两轴都塌了。读一段企业 agent 的原话："我们不裁人，但明年不招了。"再读一段员工 agent 的原话。

6. **[60s] ★ D 组对照**：那换个思路——不管企业，只提高员工的维权便利度。跑出来：正式协商比例上升、变相渠道萎缩、校招收缩幅度**小于** B 组。「与其管企业，不如给员工武器。」

7. **[40s] 谣言实验**：投一条假消息进社交场景，看它扩散、看员工提前签字、看结果偏移。「预期本身就是政策。」

8. **[20s] 收尾**：这个产品在政策发布前告诉你——它会被怎么绕开，代价会由谁承担。
