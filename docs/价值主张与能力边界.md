# 大厂 Town · 价值主张与能力边界
### v3.1 配套文档 · 用于 pitch 页面与产品边界说明

> 当前交付以政府侧政策预演和 5 分钟产品演示为主。员工“处境镜”保留为概念原型，不属于最小可交付主线。

---

# 第一部分 · 三方价值主张（pitch 用）

## 页面 A：我们服务谁

> **一句话**：我们的主用户是**政策制定者**；企业是次用户，员工是受益方。

这个不对称是刻意的。声称同时服务三方的产品,通常一方也没服务好。

```
政府   │ 决策权 ✓  付费能力 ✓  使用场景明确 ✓   → 主用户
企业   │ 决策权 ✓  付费能力 ✓  使用场景有限   → 次用户
员工   │ 决策权 ✗  付费能力 ✗  但代价的承担者  → 受益方,非用户
```

**员工不是用户,却是产品的核心**——因为他们的反应决定了政策的实际效果。不建模员工,政策模拟就是错的;但这不意味着要卖一个面向员工的预测工具。

---

## 页面 B：给政府的价值

### 我们是政策的红队,不是预测器

类比渗透测试:**不声称找到全部漏洞,只声称用极低成本找到了这几个,并指出它们的类型。**

| 交付 | 具体是什么 |
|---|---|
| **漏洞清单** | 这条规定可能从哪些渠道被绕开，方向和场景指数如何变化 |
| **二阶效应提示** | 校招塌方这类不在任何考核报表里的后果 |
| **方案相对排序** | 直接管制 vs 提高仲裁便利度,哪个副作用小 |
| **低成本预演** | 在现实试点前，先用虚拟场景检查可能出现的反应 |

### 一句话卖点

> **「在政策发布前,告诉你它会被怎么绕开,以及代价由谁承担。」**

### 可信度表达

产品首先输出方向和机制，不输出未经校准的现实概率。以下方向未来可以通过公开资料或访谈继续核对：
- 管制收紧后,外包/派遣比例应上升
- 裁员规模分布应在门槛下方堆积
- 校招名额应先于正式裁员收缩

本轮 Demo 不把核对工作包装成已经完成的实验。界面明确标记哪些内容来自背景知识、哪些来自场景规则、哪些仅仅是演示指数。

## 页面 C：给企业的价值（诚实版）

### 先说我们不做什么

**企业的 HR 和法务比任何模拟都更懂怎么合规裁人。** 我们不提供这个,也不该提供。同样,「政策会怎么变」是企业最想要的,但我们最不该给——给了也不准。

### 站得住的两条

**① 舆情风险预演**
同样裁 500 人,不同渠道组合上热搜的概率差好几倍。这个企业内部算不清,因为它取决于员工群体的情绪状态和社交网络结构——**而这恰好是 MiroFish/OASIS 的原生强项**。

**② 人才市场时序**
同行什么时候集中放人、什么时候集中开招、招聘窗口在哪。单个企业看不到全局。老师说的「企业也有动机来使用」,指的正是这个。

### 一句话卖点

> **「同行会怎么动,舆情会怎么烧,人才窗口在哪。」**

---

## 页面 D：给员工的价值

### 我们明确拒绝做的功能

**不预测个人被裁时点。** 三个理由,展示时讲出来:

**① 生态谬误**
模型输出的是群体分布,不是个体轨迹。「这类人里 30% 会在 R5 被优化」推不出「你会在 R5 被优化」。这是统计学上的硬错误,不是精度问题。

**② 私有信息缺失**
真实名单取决于绩效档案、业务线 P&L、组织政治、和直属领导的关系。这些模型一个都不知道,而它们恰恰是决定性的。模型知道的(年龄、司龄、可替代性)只是弱相关变量。

**③ 这个功能会反噬员工**
说错了制造无谓焦虑;说对了可能触发自我实现。更关键的是——**这种能力一旦存在,最有动机使用它的是企业**,用来识别谁最可能低价接受协商。

> ### ★ 展示时的原话
> 「我们本可以做一个『预测你什么时候被裁』的功能,它会很吸引眼球。我们没有做,原因有三个……」
>
> **一个知道自己边界在哪的产品,比一个什么都敢承诺的产品可信得多。** 这段话是加分项,不是免责声明。

### 我们做的两件事

**① 处境镜** —— 代表角色的群体分布，不是个人预测（概念原型，详见第三部分）

**② 决策支持** —— 真正有用的问题不是「我什么时候被裁」,而是「**如果我被通知了,签字 / 拖延 / 仲裁,各自的代价分布是什么**」。这个模拟真能回答,因为它就是员工 agent 每轮在做的决策。

### 一句话卖点

> **「不预测你的命运,但让你看清选择的代价。」**

# 第二部分 · 能力边界（独立成页,别藏起来）

## 页面 E：这个模拟能做什么、不能做什么

| ✅ 能做 | ❌ 不能做 |
|---|---|
| 揭示政策的绕开路径与**类型** | 校准过的**点预测**（「下降 43%」） |
| 二阶效应的提示 | 因果证明 |
| 方案的**相对排序** | 绝对量级 |
| 群体层面的结局**分布** | **个体层面的预测** |
| 低成本反事实 | 穷尽所有可能路径 |
| 机制解释（为什么会这样） | 时点预测 |

## 三层信息声明

标注清楚每条内容来自哪一层：

```
【K1 背景知识】场景参考了哪些公开常识或政策讨论
               —— 有来源就在界面中直接显示来源

【K2 世界规则】哪些状态更新、技能匹配或反馈规则导致了变化
               —— 用户可以点开查看，不藏在系统内部

【K3 本次运行】当前世界线产生的数值、流向和角色选择
               —— 仅代表这一轮模拟，不作现实预测
```

## 回答「为什么我愿意相信这个结果」

老师原话问的就是这个。答案不是「因为它很准」,而是:

> **「因为每个变化都能追到它看到的信息、采用的规则和做出的动作；同时，产品明确说明这些结果只属于虚拟场景。」**

# 第三部分 · 处境镜（概念原型，非本轮必做）

## 3.1 设计原则

**所有措辞必须是群体的,不能是个人的。** 这不是文字游戏,是产品定位的底线。

```
❌ 「你有 62% 的概率在第三季度被优化」
✅ 「当前模拟中，处境相近的代表角色出现了哪些不同选择」

❌ 「建议你现在开始找工作」
✅ 「在当前模拟中，提前求职通常缩短空窗，
    但也可能放弃原本可以继续争取的补偿」
```

## 3.2 交互流程

### 第一步:描述处境（3 个问题,不要更多）

用滑块或选项,**不收集任何可识别信息**：

```
1. 存款能撑几个月?          [1-2 / 3-6 / 6-12 / 12+]
2. 家庭负担?                [无 / 房贷 / 房贷+子女]
3. 你觉得同岗位再找一份工作? [容易 / 一般 / 很难]
```

> 刻意不问公司、岗位、年龄、绩效。**问得越少,越不像预测工具,也越诚实**——因为多问的那些我们也用不好。

### 第二步:匹配代表角色

在已跑完的模拟中找出处境相近的代表角色。以下仅为带水印的 UI fixture，正式演示读取当前世界快照：

```
┌─────────────────────────────────────────┐
│  当前世界中相似的代表角色：10 人            │
│                                          │
│  他们在被通知后的选择分布                 │
│  ▓▓▓▓▓▓            签字接受       6人   │
│  ▓▓▓               拖延协商       3人   │
│  ▓                 申请仲裁       1人   │
│                    公开曝光       0人   │
│                                          │
│  ⓘ 这是模拟结果,不是对你个人的预测        │
└─────────────────────────────────────────┘
```

### 第三步:代价对照（核心价值）

点开任一选择,看它的结局分布：

```
选择「拖延协商」的代表角色后来怎么样了

补偿结果    相比立即签字通常更高
空窗时间    相比立即签字通常更长
再就业结果  受招聘窗口和技能匹配影响
代表案例    有人提高了补偿，也有人错过招聘窗口

⚠️ 反直觉结论：拖延赢了谈判,但可能输了时间。
   这是场景中的机制提示，不是对真实个人的建议。
```

**这一屏是整个员工侧的价值所在。** 它回答的是一个真问题,而且答案是反直觉的、可操作的、不涉及任何个人预测。

### 第四步:权利认知（低成本高价值）

用模拟中出现过的情节做载体,说明:
- 调岗降薪、转外包在法律上意味着什么
- 经济性裁员的备案门槛与补偿标准
- 仲裁的大致周期和举证责任

**不给法律建议,只做概念普及,并明确建议咨询专业人士。**

## 3.3 必须有的护栏

这个功能触及真实的失业焦虑,以下几条不能省:

| 护栏 | 实现 |
|---|---|
| **全程群体措辞** | 文案审一遍,消灭所有「你会」 |
| **持久免责条** | 常驻页面,不是弹窗点掉就没了 |
| **不做个体评分** | 任何形式的「风险分数」都不做 |
| **不收集可识别信息** | 三个问题,不存储 |
| **导向行动而非焦虑** | 每一屏结尾都有可做的事,不留在恐惧上 |
| **提示专业资源** | 涉及法律问题时,建议咨询劳动法律师或当地劳动监察 |

## 3.4 在 Demo 里怎么用

**处境镜不是主线,是收尾的情感落点。**

放在 Demo 第 5 步(读员工 agent 原话之后):

> 「我们把这个能力做成了给员工的一面镜子——但它照的是群体,不是个人。
> 我们本可以做成预测个人被裁时间的工具,那样更吸睛。
> 我们没做,因为它在统计上是错的,而且这种能力最终会被用来对付员工。」

然后翻到能力边界那一页。

**这个顺序很重要**:先展示克制,再展示边界。评委会把这理解为专业性,而不是能力不足。
