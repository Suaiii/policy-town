## 4. 截止日、数据尝试与 Mock 滚动财政池

### 4.1 防泄露规则

历史事实的所属年份不等于信息可用时间。系统先用 `information_available_date <= cutoff_at` 过滤，再构建 Agent Context。因而滚动评级报告虽然补齐了早期财政数据，却只能从各报告公开日开始进入推演：

| 报告 | 回溯数据年度 | 信息可用日 | 不得进入的阶段 |
|---|---|---|---|
| 2011 跟踪评级报告 | 2008—2010 | 2011-06-30 | S1 |
| 2013 跟踪评级报告 | 2010—2012 | 2013-06-28 | S1、S2 |
| 2015 跟踪评级报告 | 2012—2014 | 2015-06-30 | S1、S2、S3 |
| 2016 跟踪评级报告 | 2013—2015 | 2016-06-30 | S1、S2、S3 |

这里的“不进入”包括原始观察、派生指标、财政 Agent 证据和 Agent 提示词。终局 Replay 可以读取 withheld 历史结果，但运行中的 Agent 不可读取。自动测试验证 2008 年基金数据不会因为后来报告回溯披露而泄漏至 S1。

### 4.2 来源追溯规则

产品从任一财政观察可以沿 `observation_id → source_id → URL/本地归档/SHA-256` 返回报告。评级报告中的财政表格按 `provisional` 保存；取得财政决算原表后应新增官方来源记录并升级验证状态，不静默覆盖当前来源。机器台账 `manifest.json` 记录每次归档的状态、字节数、抓取时间和哈希。

财政点数不是可投资亿元，也不是“财政收入减财政支出”的结余。虽然系统已经取得财政收入、支出、政府性基金和部分债务数据，但仍缺产业基金可用余额、真实财政结余、国有资本经营预算、项目实际政府出资与后续承诺，因此不能从现有宏观数值推出真实可投资额度。

当前点数明确标记为 `scenario_assumption`。真实财政数据仅用于财政环境研判，Mock 仅用于维持玩法闭环：

```text
new_fiscal_capacity = configured scenario_assumption

gross_resources = opening_balance + new_fiscal_capacity + exits_and_returns
available_points = max(0, gross_resources - committed_capital - maintenance_cost)
carry_out = available_points - spent
```

| 阶段 | 决策截止日 | Mock 新增点数 | 数据状态 | 校准状态 |
|---|---|---:|---|---|
| S1 | 2008-09-30 | 100 | insufficient | uncalibrated |
| S2 | 2011-12-31 | 60 | insufficient | uncalibrated |
| S3 | 2014-12-31 | 45 | insufficient | uncalibrated |
| S4 | 2016-12-31 | 30 | insufficient | uncalibrated |

例如 S1 不能使用 2008 全年公报，因为该公报在 2009-03-18 才可用；但即使使用 2007 年公报，也只能判断当时的宏观财政环境，不能把其中的收入或支出直接转换为 100 点可投资资金。

每个假设记录已尝试来源，但 `source_ids` 为空，因为这些来源没有校准点数。未来若补齐真实数据，使用 `hefei.fiscal.investable_capacity.S1` 至 `S4` replacement key 替换对应额度。

以当前演示决策为例，预算轨迹为：

```text
S1：期初 0 + 新增 100 - 承诺 0 - 维护 0 = 可用 100；投入 75，结转 25
S2：期初 25 + Mock 新增 60 - 承诺 13 - 维护 8 = 可用 64
S3、S4 同样结转上一阶段余额；具体轨迹以 demo_run.json 为准
```

## 5. 不能从当前资料推断的内容

滚动评级报告已经补齐 2008—2015 全市政府性基金预算序列。收入依次为 98.91、150.29、316.05、261.06、249.85、385.10、573.89、475.95 亿元，支出依次为 102.42、133.92、313.37、267.27、232.25、400.86、598.37、485.27 亿元。相邻报告的重叠年度数值一致，形成连续交叉核对链。报告还记录 2015 年全市直接债务余额 857.16 亿元、担保债务余额 111.69 亿元。由于这些仍是机构二次披露，状态为 `provisional`，并严格使用各报告的公开日期作为信息可用日。

当前基金序列仅仅缺 2007 年；仍缺基金中土地出让收入的逐年拆分、国有资本经营预算、财政结余以及项目实际政府出资。系统不会用 0 或模型猜测补齐这些字段；它们继续在 `data_gap` 中登记。这些观测仅仅支持财政环境、政府债务压力和资金口径研判，不直接生成玩家可用点数；玩家额度仍为 `scenario_assumption`。
