# MiroFish 人物关系网 HTML 原型设计

## 目标

交付一个可直接在浏览器打开的独立 HTML 原型，以图 2 的清爽像素风展示 MiroFish 关系网；不修改 MiroFish 源仓库和后端 API。

## 已确认的设计决定

- 交付方式：独立、单文件 HTML 原型。
- 交互范围：缩放、画布拖拽、节点拖拽、类型筛选、搜索、节点聚焦、关系高亮、详情抽屉、恢复全景。
- 人物节点：使用内嵌像素人物肖像；机构节点使用按实体类型着色的线性图标。
- 默认视图：全量关系概览；未选中时弱化普通关系，选中/悬停时聚焦一跳邻居，降低图谱噪声。
- 数据契约：演示数据保持 MiroFish 图谱字段 `uuid`、`name`、`labels`、`summary`、`attributes`、`source_node_uuid`、`target_node_uuid`，以便未来替换为 `GraphPanel.vue` 的实际输入。

## 视觉系统

- 背景：白到浅蓝灰的点阵画布；主文本为海军蓝。
- 节点：中心企业使用更大的暖色描边人物卡片；普通人物使用小型像素肖像；企业、政府、媒体、投资机构采用对应的描边机构图标。
- 连线：默认细虚线；中心实体和选中节点的一跳关系采用珊瑚红或实体类型色；无关元素降低不透明度。
- 信息结构：左上标题、右上交互工具、左下图例、右侧可关闭详情抽屉。

## 边界

- 原型不连接 API、不存储用户拖拽结果、不执行真实 D3 力导向计算。
- 原型采用确定性的分层/环形坐标，确保截图和每次打开时结构稳定、视觉接近参考图。
