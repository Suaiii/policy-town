# 合肥产业投资推演系统：5 分钟演示脚本

> 用途：现场演示 + 录屏兜底 + 评委讲解。
> 主线：截止日盲测——把 Agent 放回历史发生前，看它在不知道结果的情况下能否做出与合肥一致（或揭示分歧）的判断。
> 后端入口：`scripts/run_blind_simulation.py`（盲测）、`scripts/run_s1_agent_loop.py`（政企协商）、`policytown/investment/broadcast.py`（左侧播报流）。

## 0. 三个必须打出的反转

1. 截止日不可见：2008-09-12 决策点看不到 2009 年才发布的年报；评级报告 2011 年回溯披露 2008 数据，但不能反向进 S1。
2. 京东方逆周期：2008 行业低谷 + 金融危机投 6 代线，后来营收 62 亿 -> 689 亿，全球面板龙头。
3. 赛维高杠杆崩：2010 光伏最火时投，但母公司 2009 已净亏 2.34 亿美元、负债 35 亿美元，2014 美国破产 / 2015 中国破产。

## 1. 脚本（9 步 · 5 分钟）

### ① 0:00-0:20 抛问题（20s）
合肥 2008 年在行业低谷 + 金融危机里投了京东方；2010 年光伏最火时投了赛维。一个成了全球面板龙头，一个 2015 年破产。差别不在事后，在「当时能不能看穿」。我们今天演示的是：把 AI 放回 2008 年，它只看到当时公开的信息，会怎么决策？

### ② 0:20-0:55 截止日冻结（35s）
操作：切到 2008-09-12（S1 京东方决策点），打开左侧「固定 Context 锚点」。
话术：注意这个「信息截止日」。Agent 只能看到截止日前已经公开的材料。京东方 2008 年报是 2009 年 4 月才发布的——所以系统显示「当时不可知」。这不是我们藏数据，是当时真的没有。
点开证据抽屉：source_id -> 发布日期 -> 过滤原因，玩家模式只显「当时不可知」。

### ③ 0:55-1:30 看匿名企业申请（35s）
操作：右侧 P03 展示 2 家匿名企业卡（不显示真实原型名）。
话术：你看到的不是「京东方」「赛维」，是两家匿名企业。因为一旦你知道名字，就等于知道结果了——这是后见之明，不是当时判断。

### ④ 1:30-2:20 四部门吵起来（50s）
操作：跑 P04 四部门初审，左侧播报流同步滚出部门立场/质询。
话术：财政说预算紧，经信说逆周期该进，科技问量产证据，发改看全球周期。政策不是一个人拍板的，是四个 KPI 相反的部门吵出来的。左边每一条播报，点开都能回到它引用的证据。

### ⑤ 2:20-3:20 关键命题穿透（60s）
操作：跑政企协商（run_s1_agent_loop.py），选核验问题 -> 企业回应 -> 条件单 -> 反提案。
话术：我们不是泛泛问「项目好不好」，而是锁定那个最可能翻转决策的命题。京东方：你有没有验证过的建线、融资、扩代能力？赛维：你母公司 2009 年已经亏 2.34 亿美元、负债 35 亿，还能不能持续输血？企业只能披露、给区间、拒答、或要求交换条件——不能捏造。

### ⑥ 3:20-3:40 结算与沙盘变化（20s）
操作：P07 结算 -> P08 左侧播报「结算成功」+ 底部资源条刷新 + 中央地块随 StateDelta 变化。
话术：投钱的地块长高亮灯，退出的地块熄灯变暗。每个变化都能点开看 reason_code 和证据。

### ⑦ 3:40-4:20 终局解密（40s）
操作：P09 解密真实原型 + 双时间线。
话术：现在解封。京东方——Agent 在当时判断「有条件支持」，和历史一致，后来它成了全球面板龙头。赛维——Agent 当时也看到光伏火热，但穿透了母公司现金流这个命题。如果它在不知结果的情况下识别出这个风险，就是这套系统的价值；如果它和当年合肥一样投了、后来崩了，那正好说明「当时的信息根本不足以看穿」——这也是一个诚实的结论。

### ⑧ 4:20-4:50 双组评价（30s）
操作：P09 展示「决策过程评价 + 历史校准评价」（prediction_metrics / replay_baseline）。
话术：我们不评「你比合肥高多少分」，只评两件事：决策过程对不对（证据纪律、财政纪律、条件可执行），推演机制和历史方向一不一致（方向、时序、机制、泄漏审计）。

### ⑨ 4:50-5:00 收尾（10s）
我们不是把答案喂给 AI，而是把 AI 放回历史发生前。真实数据 + 截止日冻结 + 可回溯的推演——这就是我们的方法论。

## 2. 兜底预案

1. 断网 / LLM 超时：所有 Agent 都有确定性 fallback，不设 INVESTMENT_AGENT_LLM 时就是纯规则跑，演示不受影响。
2. 现场挂掉：录屏一段「盲测 -> 四部门 -> 终局解密」的完整回放，随时切。
3. 前端没接完：退化为「后端 CLI + 讲解 + JSON」，技术评委能懂，产品评委靠上面的叙事补。
