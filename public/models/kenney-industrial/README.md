# Kenney City Kit (Industrial)

Selected GLB assets from [Kenney City Kit (Industrial)](https://kenney.nl/assets/city-kit-industrial).

- License: CC0 1.0 Universal
- Included models: `building-h`, `building-p`, `building-q`, `building-r`
- Shared palette texture: `Textures/colormap.png` (required by all four GLB files)
- The original license text is preserved as `License.txt`.

These files are composed into anonymous project-parcel archetypes. They never display a company name or logo and are only shown as completed buildings after physical construction reaches 90%.
